# Bitrix Task Files List

Минимальное браузерное расширение для Chromium, которое заменяет стандартную плитку файлов в задаче Bitrix на список прямо на её обычном месте и подсвечивает статусы задач в списке.


## Как запустить

1. Откройте `chrome://extensions/`
2. Включите `Developer mode`
3. Нажмите `Load unpacked`
4. Выберите папку проекта `b24_ext`

## Поддержка слайсеров

Расширение добавляет быстрые кнопки открытия моделей в локальных слайсерах:

- `Lychee`
- `Bambu Studio`

Кнопки появляются рядом с поддерживаемыми файлами моделей в списке вложений задачи. Сейчас запуск слайсеров рассчитан на файлы `.stl`, `.step` и `.stp`.

Для работы кнопок нужен native messaging host:

1. Установите расширение через `Load unpacked`.
2. Скопируйте ID расширения на странице `chrome://extensions/`.
3. Запустите PowerShell из папки проекта:

```powershell
.\install-native-host.ps1 -ExtensionId "ID_РАСШИРЕНИЯ"
```

Скрипт соберёт `native-host/Program.cs`, создаст манифест native host и зарегистрирует его в текущем профиле Windows для Chrome.

## Подсветка статусов задач

Штатный Bitrix рисует завершённые задачи бледно-серым зачёркнутым шрифтом (`#ccc`), а отложенные — тем же бледным серым. В расширении бледность и зачёркивание убраны, заголовок становится тёмным и жирным, а строка получает цветной фон:

- завершённая задача — тёмный (`#333`) жирный заголовок без зачёркивания, фон строки светло-зелёный `#e6f7e6`;
- отложенная задача — тёмный (`#333`) жирный заголовок, фон строки голубой `#e5f2fc`.

Жирность задаётся прямо на самом заголовке по его статусному классу `.task-status-text-color-completed` / `-delayed`, поэтому она держится и в том случае, если подсветка фона перестанет находить строку после обновления вёрстки Bitrix. Фон вешается на строку через `tr.main-grid-row:has(...)` — это более хрупкая часть, её при смене разметки, возможно, придётся поправить. Нужен браузер с поддержкой `:has()` (Chrome 105+, Edge 105+, Firefox 121+).

## Как это работает

Скрипт не добавляет внешний виджет. Он находит стандартный блок файлов задачи:

- `.tasks-field-files`
- `.tasks-field-files-list`
- `.ui-tile-uploader-item-preview-content`

После этого скрывает штатные плитки и строит на их месте обычный список ссылок.

Для файлов моделей под именем файла также появляются быстрые кнопки:

- `Lychee`
- `Bambu Studio`

Кнопки запрашивают у Bitrix публичную ссылку на файл через `disk.file.getExternalLink`, скачивают модель во временную папку загрузок `Bitrix slicer` и передают её в локальное приложение через native messaging без открытия новой вкладки.
